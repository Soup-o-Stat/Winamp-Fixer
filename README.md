# Winamp Fixer
!()[https://github.com/Soup-o-Stat/Winamp-Fixer/blob/main/winamp_fixer.png]
## What is it?
Winamp Fixer is a program that restores your Winamp without reinstalling the player itself (For example, when Winamp crashes when selecting a song)
## How to use it?
* To get started, close Winamp and run Winamp Fixer.exe
* Follow the on-screen instructions
* After fixing Winamp, the backup files will be copied to the Winamp Fixer directory
* Launch Winamp

## Results
After successful completion of the program, your Winamp will be operational again. Important: your saves (skins, etc.) will disappear, but you can configure everything when you start the player. All plugins will be saved and you won't need to configure them again
